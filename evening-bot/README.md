# Вечерний бот

Телеграм-бот: вечером спрашивает, как прошёл день, расшифровывает голосовое и кладёт текст в Notion, в базу «Дневник дня». Весь код — в файле `worker.js`.

## Установка (один раз, около 15 минут)

Ключи никому не пересылай и не вставляй в чаты — только в настройки Cloudflare.

### 1. Бот в Телеграме
1. Открой @BotFather, отправь `/newbot`, придумай имя и логин.
2. Сохрани токен, который он пришлёт.

### 2. Ключ ElevenLabs
1. elevenlabs.io → Developers → API Keys → Create API Key.
2. Включи доступ к Speech to Text и сохрани ключ.

### 3. Интеграция Notion
1. notion.so/profile/integrations → New integration, тип Internal.
2. Сохрани Internal Integration Secret.
3. Открой в Notion базу «Дневник дня» → `•••` → Connections → добавь свою интеграцию.

### 4. Cloudflare
1. Зарегистрируйся на dash.cloudflare.com.
2. Compute (Workers) → Create → Start with Hello World → назови `evening-bot` → Deploy.
3. Edit code → удали всё, вставь содержимое `worker.js` → Deploy.
4. Settings → Variables and Secrets → добавь четыре секрета (тип Secret):
   - `TELEGRAM_TOKEN` — токен из шага 1
   - `ELEVENLABS_KEY` — ключ из шага 2
   - `NOTION_TOKEN` — секрет из шага 3
   - `WEBHOOK_SECRET` — любая строка из латинских букв и цифр, придумай сам
5. Settings → Trigger Events → Add → Cron Triggers → добавь два расписания (время там в UTC, то есть Москва минус 3 часа):
   - `43 17 * * *` — вечерний вопрос в 20:43 по Москве;
   - `40 20 * * *` — итог дня в 23:40 по Москве. Это выражение менять нельзя без правки `SUMMARY_CRON` в коде.

### 5. Подключение
1. Открой в браузере `https://<адрес-воркера>/setup?key=<твой WEBHOOK_SECRET>` — должно появиться «Готово: бот подключён».
2. Напиши боту `/start` — он пришлёт твой ID.
3. Добавь в Cloudflare пятый секрет `OWNER_CHAT_ID` с этим числом. После этого бот отвечает только тебе.
4. Отправь боту голосовое — в ответ придёт расшифровка и ссылка на запись в Notion.

## Как пользоваться
- Голосовое, кружок, аудио или текст можно присылать в любой момент, не только вечером.
- Всё за один день дописывается в одну страницу; записи до 4 утра относятся ко вчерашнему дню.
- Файлы больше 20 МБ Телеграм боту не отдаёт — это примерно час голосового.
- В 23:40 бот присылает итог дня: его готовит агент Claude, который в 23:13 разбирает записи в Notion и заполняет свойство «Итог для Телеграма».
- Чтобы изменить время вечернего вопроса, поменяй первый Cron Trigger в Cloudflare.
